# Automated ACL Segmentation and 3D Geometric Analysis

## Project Description

This project, titled **2509-MRI-Knee**, is developed by **Viliam Bartoš** under the supervision of **Ing. Jakub Lázňovský, Ph.D.** This project is developed as part of a Diploma Thesis. It provides medical imaging pipeline for the segmentation of the Anterior Cruciate Ligament (ACL), Femur, and Tibia from 3D Isotropic MRI scans. The repository also contains scripts for automated 3D measurement of knee joint geometry.
