## Repository Setup

1. **Create Initial Issue from Template**
   - Go to the Issues tab and click on "New Issue."
   - Select the `InitializeRepository` issue template. This template includes the necessary steps to set up the repository.
   - Submit the issue to track the initialization process.

2. **Repository Structure**
   - .github - optional repository for adding issue templates etc.
   - Data
      - Use this folder for larger files which are not code or text (ML models, example data, ...).
      - Do not use this as primary data storage. The repository is primarily for code and text. Upload only the minimum necessary amount of data needed for function or demonstration of the code
   - Documentation - Use this folder for text - manuals, reports, etc.
   - Source - use this folder for code.
   - Root folder contains the main readme of the repository. Feel free to edit it as necessary.
   - Feel free to structure the Data, Documentation, and Source folders in a way that is convenient to you
